# QuotAI

macOS 原生菜单栏额度工具，支持 Codex、Antigravity 和 Claude Code。各来源独立读取、独立显示，
同时提供 Codex Token 活跃度和“保持唤醒”功能。运行要求为 macOS 14 或更新版本。

## 功能

- **订阅额度**：显示可用的 5 小时、7 天剩余额度、重置时间与套餐；Codex 还显示重置卡。
- **按安装情况显示**：未安装或未启用 Antigravity 时隐藏对应标签；只剩 Codex 时隐藏切换栏。
  配置和缓存残留不视为安装；卸载后临时回退 Codex，保留原来的来源偏好。
- **菜单栏**：供应商图标配合一行或两行额度；可选择来源、Antigravity 模型组及显示窗口。
  左键打开面板，右键快速刷新、打开设置或切换唤醒状态。
- **Codex Token 活跃度**：支持累计用量、连续天数和最近 18 周图表，大数自动使用 M / B 单位。
  Antigravity 页面只显示额度；Claude Code 页面显示官方 `/usage` 查询的 5h/7d 与重置时间。
  Claude Code 不显示重置卡、查看入口或 Token 统计。
- **外观**：四种热力图配色，适配浅色、深色和增强对比度；统一半透明卡片与原生工具按钮。
- **保持唤醒**：支持定时或持续开启，可选择是否同时保持显示器唤醒。
- **语言**：English 与简体中文，默认跟随系统，也可在 macOS 的应用程序语言设置中单独指定。

## 开始使用

QuotAI 是菜单栏 App，不显示 Dock 图标。安装后打开菜单栏图标，按使用的来源完成准备：

| 来源 | 准备条件 |
| --- | --- |
| Codex | 本机 Codex / ChatGPT 已登录订阅账户；API Key 登录不提供订阅额度 |
| Antigravity | 已安装、登录并正在运行；Gemini、Argon 独立周额度与 Claude/GPT 按账号权限及实际额度池分组显示 |
| Claude Code | 已安装并登录 Pro/Max 订阅的 Claude CLI，在设置中启用，然后点击刷新 |

缺失数据不会显示成 0。Claude Code 的刷新按钮执行一次官方 CLI `/usage`，无需等待进行中的会话回调；
查询期间可取消，20 秒超时。启动时载入额度缓存，默认仅手动查询；可在“功能”设置中选择 15/30/60 分钟的低频查询，不生成模型回复。
首次启用与启动时读取官方 CLI 的套餐名称，之后随手动刷新更新；仅缓存套餐标识，不保存账号资料。
界面标注查询完成时间；超过 30 分钟、载入缓存或查询失败后，旧结果灰显并注明“上次查询”。
各窗口达到重置时间后隐藏旧数字，需刷新取得新额度。官方输出没有源采样时间或账号标识，
查询结果不表示后台持续实时监控。
重置后尚未使用时，CLI 可能没有有效重置时间；该窗口显示暂不可用，其余有效窗口仍独立显示。
两个窗口都没有有效重置时间时清除旧数字，不推算为 100%，也不作为格式错误。
Claude CLI 登录成功但未返回订阅额度时，请检查 CLI 的网络连接；使用按可执行路径分流的 VPN 时，CLI 升级后可能需要更新规则或重连。
QuotAI 不读取 Antigravity 本机会话 Token。
从旧版本升级时，会识别并恢复由 QuotAI 安装的 Claude Code 状态栏配置；历史缓存保留且不再读取。
完整口径和隐私边界见[数据来源与隐私](docs/data-sources.md)。

当前 GitHub Release 使用 Apple Development 团队签名，尚未完成 Developer ID 公证。安装包应来自可信来源；安装与本机构建说明见
[开发与验证](docs/development.md)。如安装了 Bartender 等工具，需要将 QuotAI 设为始终显示。

## 保持唤醒

使用 macOS 原生活动断言，不依赖 Caffeine 或 `caffeinate`。默认只阻止空闲系统睡眠，
显示器仍可息屏；也可以同时保持显示器唤醒。支持 5/10/15/30 分钟、1/2/5 小时或无限期。

有限时长到期后释放，无限期状态在 App 重启后恢复；运行中切换显示器模式不会重置到期时间。
退出 App 会释放断言。该功能不阻止手动睡眠、合上 MacBook 屏幕或系统因低电量等原因睡眠。

## 3.0 可选功能

设置中的“功能”页提供额度低位/确认重置通知、本机额度趋势、桌面小组件共享、⌃⌥Q 全局快捷键和 Claude 低频自动查询，均默认关闭。趋势数据仅保留最近 30 天或 12,000 条，可暂停或清空；提醒的首次读取只建立基线，不凭时钟推断额度已恢复。

“关于”页使用 Sparkle 2.9.6 检查更新，可自行启用自动检查及自动下载。更新包采用 Ed25519 签名，解压前验证；检查请求不附带额度或账户资料。只有已上传并验证的版本才会加入生产更新源。

桌面小组件需要使用同一 Apple 团队签名的 App 与扩展，通过 App Group 共享最近一次查询的最小快照。CI 的 ad-hoc 包无法建立团队共享容器，会在设置中说明。当前未新增数据源，现有三个来源已接入统一可扩展的注册表。

在组件库添加 **QuotAI · 可选额度**，再右键它 → **编辑小组件** → **额度**，可为每个组件独立选择 Codex、Claude Code 或 Antigravity 的具体模型组。默认“自动总览”保留小号跟随菜单栏、中号显示三个来源的行为；已有组件保留为自动总览，无需删除；固定选择不随菜单栏切换。7d 为外环、5h 为内环，Claude 与 Antigravity 保留彩色品牌图标，Codex 使用其原有单色标志。可选额度来自已开启共享的最近查询；选择暂时不可用的额度时会显示提示，不自动换成其他额度。

应用内更新后，3.0.4 起会安全回收本应用的旧 Widget 扩展并请求系统刷新，不再主动修改系统注册或使已有 AppIntent 配置失效。若组件仍停在占位状态，可在设置 → 功能 → 桌面小组件点击“修复小组件”。修复保留现有桌面组件、固定额度选择和分享开关，不重新查询供应商。
