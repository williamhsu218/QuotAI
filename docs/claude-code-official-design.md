# Claude Code 官方额度设计

2026-10-01。设计由本机 Claude CLI 的 **Claude Opus 5.5 / high** 完成，Codex 审查数据边界与实现。
用户已确认继续实现，并要求验收通过后替换本机应用、发布 GitHub Release。

## 展示内容

Claude Code 独立页面只显示官方状态栏最近报告的 **5h、7d 剩余额度和北京时间重置时间**。
不显示重置卡、任何查看入口、套餐或每日 Token；用户自行在 Claude Desktop 查看重置卡。
原始草案中的重置卡区域已经取消。

官方字段为 `rate_limits.five_hour` / `seven_day` 的 `used_percentage` 和 `resets_at`。
状态栏没有源采样时间或账户标识，不能解释为持续实时查询；本机收到时间也不能冒充服务端刷新时间。
依据：[官方状态栏额度说明](https://code.claude.com/docs/en/statusline#rate-limit-usage)。

## 数据与界面边界

- 340 pt 原生面板，卡片标题「本机报告」。缺少一个窗口时不补旧值。
- 各窗口分别标记首次收到当前值的时间；5h 变化不让未变化的 7d 报告变新。
- 相同窗口值的重复回调不延长 30 分钟本机展示期限。期限不是官方有效期，也不证明数据实时。
- 超过展示期限、时钟回拨或达到重置时间时隐藏百分比和进度，辅助功能也不朗读旧数字。
  不推算为 0% 或 100%。
- 多会话分别保存，载入后默认选择最近可显示的官方报告；用户可固定会话。每次只显示一个完整会话的报告，不合并为全账户用量。识别会话以官方回调为依据，不扫描对话或凭据，也不把最近回调声称为进程仍在运行。
- 菜单栏报告数值带 `~`，提示框说明报告口径；不可用时不会借用 Codex 数据。
- CLI 正常使用自动生成 JSON；QuotAI 仅在启动、接入或手动刷新时载入，不监听报告文件自动变化。刷新只重新读取本机记录，不启动 Claude 模型请求；已载入窗口到期仍按时隐藏。

## 接入与恢复

使用独立辅助程序 `Contents/Helpers/quotai-claude-statusline`，不复用旧的退役命令或启用偏好。
接入操作先保存恢复记录和原字节备份，再修改 Claude 用户设置的状态栏命令。
保留原命令的 stdin、stdout、padding 和 refreshInterval；停用仅恢复仍属于 QuotAI 的配置。
用户自行改写、文件损坏、符号链接或冲突时停止覆盖。

只保存白名单额度字段、会话指纹与本机时间；输入、文件和会话数量有上限，写入有锁、私有权限和原子替换。
不读取原始对话、凭据、钥匙串、桌面缓存或 CLI 私有模块，不调用未公开 OAuth 接口。
