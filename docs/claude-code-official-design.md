# Claude Code 官方额度设计

2026-10-02。方案设计由本机 Claude CLI 的 **Claude Opus 5.5 / high** 复核，Codex 负责数据边界、实现与交付验收。

## 展示与刷新

Claude 页面显示官方 `/usage` 的 **5h、7d 剩余额度和北京时间重置时间**。
不显示重置卡、查看入口、套餐或每日 Token。刷新直接查询，无需选择或等待 Claude 会话。

本机 Claude CLI 2.1.285 已验证：
`claude -p /usage --output-format json --no-session-persistence` 返回零对话轮次、零费用、
空 `modelUsage`；额度位于 `result` 的文字中，并非结构化额度字段。
官方命令依据：[Commands](https://code.claude.com/docs/en/commands)、
[Headless](https://code.claude.com/docs/en/headless)。

该方式调用官方本机命令，不代表 Anthropic 提供了独立的第三方订阅额度 HTTP API。
文字格式发生变化时明确失败；不从模型回复、会话记录或费用估算额度。

## 状态规则

- 每次明确刷新仅启动一次查询；重复点击不会并发，刷新中按钮变为“取消”，单次最多 20 秒。
- 启动只读取专用查询缓存，不自动调用 CLI。后台刷新其他来源也不查询 Claude。
- 成功查询更新本机完成时间，即使百分比相同。没有源采样时间或账号标识，不声称绑定账户或持续实时。
- 缓存载入、超过 30 分钟或查询失败时，仍有效的窗口灰显并注明“上次查询”；失败保留旧结果。
- 到各窗口重置时间后隐藏该窗口数字，不推算为 0% 或 100%。系统时间回拨时隐藏数字。
- 只接受独立有效的 5h、7d 行；缺少窗口不拼接旧值。菜单栏带 `~`，与其他来源相互隔离。
- 清除、停用和退出会取消当前查询；迟到结果无法重新写回已清除的数据。

## 进程与隐私

在空临时目录启动已安装的 Claude CLI，设置英文语言、禁用 hooks、MCP 与工具，
不持久化会话。官方 CLI 自行处理已有登录；QuotAI 不读取凭据、钥匙串或会话正文，
不调用未公开 OAuth 接口。输出有 1 MiB 上限，错误输出不持久化。

解析严格检查结果类型、零轮次、零费用和空模型用量；拒绝模型响应或非零 Token。
日期按官方输出时区解析，处理跨年和各窗口合理范围；无时区、日期不合法或夏令时重复时间时失败。
缓存只保存白名单额度与本机时间，使用独立文件、0600 权限和原子替换。

## 升级与验收

停止旧 v2 状态栏采集后，仅恢复仍由 QuotAI 持有的配置；用户改写的命令不覆盖。
旧报告、配置备份与恢复记录保留，且不作为新数据源。

分别验收解析与时间规则、隔离子进程/状态生命周期、完整 App 与 Universal 构建、
中英文及明暗渲染、原生设置/面板、真实官方查询、安装版刷新和 Release 产物读回。
实际结果见 [2.1.1 版本说明](../Design/release-notes-2.1.1.md)。
