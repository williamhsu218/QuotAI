# 界面设计与验收

QuotAI 使用 macOS 原生菜单栏与弹窗，保持紧凑、清晰的额度信息层级。
本文描述当前设计约定；数据口径与隐私边界见[数据来源](data-sources.md)，
构建和预览入口见[开发说明](development.md)。

## 材质与颜色

- 外层材质由原生 `NSPopover` 提供，不叠加第二层整面板玻璃。
  macOS 26 使用系统 Liquid Glass，旧系统沿用自适应材质回退。
- 额度、重置、Codex Token 与保持唤醒卡片统一使用 `appCardSurface`。
  不在共享卡片前增加不透明的整卡底色；独立预览保留自适应表面回退。
- 颜色表达状态：额度低于 20% 为红色、20–49% 为橙色、50% 及以上为绿色；
  进度轨道保留 20% 与 50% 阈值标记。重置卡使用靛蓝，保持唤醒的激活状态使用橙色。
  未激活控件保持中性色，正文与分隔线使用系统语义颜色。
- Codex Token 主题作用于不透明色块、标记和主题预览，不决定卡片容器材质。
  主题中的参考底色仅用于色阶校准，不保证任意玻璃背景上的固定对比度。

## 页面与数据来源

- 面板宽度保持 340 pt，使用紧凑单屏布局，不增加纵向滚动容器。
  缺少额度窗口时移除对应行，避免为不存在的内容保留空白。
- Codex 与 Antigravity 各自显示其额度、套餐、状态及刷新结果。
  Codex 重置卡只出现在 Codex 页；不可用或缺失数据不显示为 0，也不借用其他来源。
- Antigravity 标签仅在检测到真实安装且已启用时显示；只有 Codex 时隐藏切换栏。
  已选来源暂不可用时回退 Codex，但保留用户原来的来源偏好。
- Antigravity 只显示居中的 Gemini、Claude / GPT 两个额度标签，一次显示一组。
  面板组选择独立于菜单栏组选择；切换只更新显示，不读取会话或 Token 历史。
- 不保留 Claude 独立页面、菜单栏数据源或设置入口，也不以空卡片代替已移除的功能。
- 来源切换同步更新选中状态、内容和刷新目标，不加入等待旧页面退出的动画。
  额度刷新可保留尊重“减少动态效果”偏好的数值与进度动画。

## Token 图表

- Codex 提供海蓝（默认）、翠绿、紫罗兰、琥珀四种主题，
  选择即时生效并保存，适配浅色、深色和增强对比度。
- 最近 18 周使用本地时区的公历、周一至周日方格。
  浅色外观随用量增加而加深，深色外观随用量增加而变亮。
- 保留累计用量、连续天数与日期详情；数据来自 Codex 账户接口，不将刷新时间用于历史归档。
  日期交互只查看当前内存数据，不触发额外读取。

## 字体、控件与素材

- 使用原生系统字体、语义字重与等宽数字；优先复用 `AppTheme` 的字号、间距和动画参数。
  正文及次要文字随系统外观调整，不通过降低整个菜单栏图标和数字的透明度表达陈旧数据。
- 刷新、设置、更多统一为原生无边框工具按钮，使用一致的 28 × 22 pt 图标区域。
  更多保留原生菜单语义，不显示重复箭头；图标按钮保留可访问名称和悬停说明。
- 来源按钮明确暴露选中状态；额度行合并可访问描述，避免 VoiceOver 重复朗读。
  设置使用原生控件，支持英文与简体中文；额度重置与卡片到期时间按北京时间显示。
- 菜单栏与设置预览共用 `MenuBarStatusRenderer`，保持供应商图标、单双行额度与文字一致。
  无数据显示 `--`，仅一个可用窗口时居中单行；保持唤醒咖啡杯位于最左侧。
- [AppIcon 主稿](../Design/AppIcon-master.png)保留完整应用图标；
  [AppMark 主稿](../Design/AppMark-master.png)用于透明页头标记，不带应用图标的外部方形底板；
  [CodexMark 主稿](../Design/CodexMark-master.png)供菜单栏及预览使用。
  生产资源位于 `Assets.xcassets`，主稿仍是预览脚本依赖，不能视为备份删除。

## 验收边界

界面变更至少检查中英文、明暗外观、空数据和缺失窗口；涉及热力图时检查空数据、
零值、主题及增强对比度。涉及原生菜单、分段控件或设置窗口时，应在原生窗口中检查交互。
SwiftUI `ImageRenderer` 不支持部分原生控件，离线图片不能替代其验收。

当前范围还需检查 Antigravity 移除 Token 卡片后的紧凑布局、仅有 Codex 时的标签行为，
以及旧 Claude 来源偏好的回退。版本验收状态集中记录在[当前版本说明](../Design/release-notes-2.0.16.md)。
隔离原生视图使用合成数据，其渲染与交互结果不代表已安装 App 的弹窗验收。
源码测试、候选构建、隔离原生界面、安装包与运行进程读回应分别记录；
不从其中一项推断其他项、多屏边缘、纯悬停、VoiceOver 语音或长期能耗已通过。
