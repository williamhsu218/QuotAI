# QuotAI 3.0.5（68）

- 修复 Quota History 在鼠标查看不同模型、不同额度记录时的窗口抖动：固定曲线、图例和选中详情区域的高度，由原生窗口管理尺寸。
- 新增历史明细表，按时间从新到旧显示记录时间、来源、模型与额度周期、剩余百分比及进度条、重置时间。长名称支持截断与完整提示。
- 图例改为可横向滚动的固定高度区域；系列颜色在筛选间保持一致，同一时间的多项记录可一并查看详情。
- 鼠标选中状态与表格隔离，历史过滤及极值采样仅在数据、筛选条件或时间范围变化时重建；图表简化不影响明细表的完整记录。
- 保留原有额度查询、记录开关、按分钟合并、清空确认、30 天/12,000 条保留规则及小组件配置。

验证：169 项核心测试及本机 Debug 构建通过；已检查中英文、浅色/深色、空状态、最小窗口及 12,000 条记录下的滚动和筛选。本机安装测试构建 3.0.4（67）的鼠标移动与滚动效果已由用户验收通过；3.0.5（68）使用相同功能代码。发布包沿用 Apple Development 团队签名与 App Group，尚未完成 Developer ID 公证。
