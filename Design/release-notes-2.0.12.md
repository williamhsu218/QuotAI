# QuotAI 2.0.12

## 更新内容

- 修复 Antigravity 正在运行、会话库为 WAL 格式但缺少 sidecar 时，本机 Token 历史可能一直无法读入的问题。对符合安全条件的源文件创建私有写时复制快照，在快照上只读检查与解析；源文件保持原样。
- Antigravity Token 卡片显示会话读取进度、已记录调用数，以及未计入、无法读取、日期未知的数量。较长历史可点击「继续读取」分批补齐。
- 区分会话尚待读取、日期缺失、旧数据未刷新和历史安全上限，避免把部分统计误认为完整或将缺失日期显示为零。
- 保持本地按需读取，不添加后台轮询、文件监听或网络扫描；Token 与 Codex 额度仍使用独立的数据链路。

## 安装与验证

- 版本：2.0.12，构建号 29；macOS 14+；Universal ZIP 包含 Apple Silicon 与 Intel 架构。
- 70 项 Core 测试通过；中文深色和英文浅色的隔离原生预览完成布局与「继续读取」交互检查。
- 随附 `SHA256SUMS-2.0.12.txt`，用于核对下载包。
- 沿用 ad-hoc 签名，未使用 Apple Developer ID 或 Apple 公证。解压后将 `QuotAI.app` 放入“应用程序”并替换旧版本。

本机 Token 数字来自保留的 Antigravity 会话，并非账户全设备总量或账单用量。
