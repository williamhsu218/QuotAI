# QuotAI 3.0.2（56）

修复覆盖更新后桌面小组件仍显示旧布局或灰色占位的升级恢复缺口。

- 每次版本或安装路径变化后，刷新本应用的 Launch Services 注册，回收经过路径、用户、Bundle ID 和签名团队校验的本应用扩展进程（包括 Finder 移走的旧应用内仍存活的扩展），再发布当前共享快照并有限次请求新时间线。
- 设置 → 桌面小组件增加“修复小组件”，保留已有组件与配置，不重新查询供应商。
- 快照写入失败后，相同数据也可重试；增加扩展构建号与快照读取结果日志，便于区分注册、共享和渲染问题。
- 不重启系统组件、不删除系统 WidgetKit 容器、不改变组件 kind、Bundle ID、App Group 或已有分享开关。

## 验证

测试、签名包、覆盖升级与系统接受新时间线的证据记录于 `build/qa/widget-upgrade-fix/`。外部报告机器的最终显示仍需其安装后确认。
