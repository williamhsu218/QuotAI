# QuotAI 2.0.13

## 更新内容

- 重新设计 Token 活跃度配色：使用不透明的分级色块与独立底板，改善浅色背景和透明面板上低用量方格不易辨认的问题。
- 在「设置 → 通用 → Token 活跃度配色」中提供海蓝（默认）、翠绿、紫罗兰、琥珀四种主题，附色阶预览。选择即时生效，重启后保留。
- Codex 与 Antigravity 活跃度图共用所选主题，自动适配浅色、深色及系统增强对比度。浅色外观用量越高颜色越深，深色外观用量越高颜色越亮。
- 提高日期、图例和今天／悬停边框的可见度。Antigravity 的未知、部分数据及未刷新状态继续使用虚线和文字标识。

## 安装与验证

- 版本：2.0.13，构建号 30；macOS 14+；Universal ZIP 包含 Apple Silicon 与 Intel 架构。
- 74 项 Core 测试通过；四主题浅深色渲染、原生设置切换、即时更新及重启后偏好保留已在隔离预览应用中验证。
- 随附 `SHA256SUMS-2.0.13.txt`，用于核对下载包。
- 沿用 ad-hoc 签名，未使用 Apple Developer ID 或 Apple 公证。解压后将 `QuotAI.app` 放入“应用程序”并替换旧版本。

本次仅调整显示与主题偏好。Codex 与 Antigravity 仍使用独立的数据链路；Antigravity 本机 Token 数字来自保留的会话，并非账户全设备总量或账单用量。
