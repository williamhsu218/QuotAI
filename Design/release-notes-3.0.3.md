# QuotAI 3.0.3（59）

- Claude Code 小组件图标使用原有彩色品牌素材；Antigravity 保留彩色，Codex 保持自适应单色标志。macOS 15 起为彩色图标指定 full-color 渲染。
- 添加“QuotAI · 可选额度”组件后，右键它 → 编辑小组件 → 额度，可独立选择来源和 Antigravity 模型组。默认自动总览保留小号跟随菜单栏、中号显示三个来源的行为；固定选择始终读取该额度组。
- App Group 快照共享已启用来源的各额度组，不增加网络或 CLI 查询。组件继续显示 7d 外环、5h 内环，保留过期隐藏、历史灰显和缺失虚线环。
- 保留原静态组件的标识和自动总览行为，新增独立标识的可配置组件。覆盖更新时不把无 Intent 的旧实例重新解释为可配置组件，避免 macOS 1103 时间线拒绝；已有组件无需删除。
- 修复升级时旧扩展把旧组件清单缓存到新版本的问题：先等待经签名核验的旧扩展退出，再仅刷新本应用扩展的注册；不注销主应用、不重启系统服务、不清除小组件容器或用户配置。注册工具有超时和失败恢复。
- 共享关闭或模型暂时缺失时保留组件配置并提示不可用，不回退到其他额度；旧快照兼容读取。

验证：166 项 Swift 测试通过；独立探针验证写入恢复、关闭共享、模型组发现、选择与恢复；浅色/深色、总览、Claude 单来源及额度缺失的离线原生渲染已检查。签名包与本机安装状态见 `build/qa/widget-configuration/verification.json`。“可选额度”的实际切换和彩色图标已由用户确认；覆盖更新时还需核对组件清单与已选配置的保留。当前版本尚未发布到 GitHub Releases。
