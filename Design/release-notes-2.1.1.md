# QuotAI 2.1.1

- Claude 页的刷新按钮直接执行一次官方 CLI `/usage`，无需等待会话回调或手动生成 JSON。设置页也可单独刷新 Claude。
- 查询期间显示“取消”，支持单次 20 秒超时、连续点击保护与子进程清理。刷新不生成模型回复，启动只读取缓存，不自动轮询 Claude。
- 显示 5h、7d 剩余额度、北京时间重置时间和查询完成时间；取消会话选择，缺失窗口不拼接旧值。
- 缓存载入、超过 30 分钟或查询失败时，旧结果灰显并注明上次查询。到各窗口重置时间后隐藏数字，不推算为 100%。
- 升级时安全停用旧状态栏采集并恢复仍由 QuotAI 持有的配置。保留旧报告和配置备份，支持停用后清除新查询缓存。
- Claude 页继续不显示重置卡、查看入口、套餐或每日 Token；Codex 与 Antigravity 的数据来源保持独立。

官方 CLI 自行处理已有登录，QuotAI 不读取凭据或会话正文。查询禁用 hooks、MCP 与工具，不持久化会话；只接受零轮次、零费用、空模型用量的内置结果。

本机 Claude CLI 2.1.285 已验证该调用方式。官方输出的额度位于 JSON 的文字结果中；格式不匹配时提示失败。这里显示本次查询快照，不是持续实时监控，也不是独立的第三方订阅额度 HTTP API。

已完成验收：

- 104 项核心测试通过，覆盖解析、时区、跨年、夏令时、重复与缺失窗口、历史与重置时间、私有缓存、旧配置恢复等边界。
- 实际隔离子进程探针通过超时、取消后同步回收、输出上限、启动无查询、并发保护、清除/停用拒绝迟到结果及停用后清除缓存。
- Debug 构建及 arm64 / x86_64 Universal 包通过，主程序与兼容辅助程序的 ad-hoc 签名检查通过。
- Claude Opus 5.5 high 完成方案及实现复核；原生预览面板/设置、中英文与明暗状态渲染通过。
- `/Applications/QuotAI.app` 已替换为 2.1.1（38），与安装包内容一致；安装版通过按钮实际取得 5h/7d 和北京时间重置时间。CLI 内置查询的零模型结果已在真实链路验证。
- 安装版界面没有 Claude 重置卡、Token、会话选择或外部查看入口；旧 Claude 配置按原字节恢复，保持唤醒和原有偏好保留。

本版采用个人本机使用的 ad-hoc 签名，支持 macOS 14 及更新版本。
