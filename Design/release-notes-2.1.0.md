# QuotAI 2.1.0

- 新增 Claude Code 独立额度页和菜单栏来源，读取官方状态栏报告的 5h/7d 剩余额度与北京时间重置时间。
- 明确显示本机报告与收到时间。两个窗口分别计时，相同报告不延长展示期限；超过 30 分钟或达到重置时间后隐藏数字，等待新报告。
- 载入后默认选择最近官方报告，可手动固定会话；多会话分别查看。缺失数据不显示为 0，也不合并为全账户实时统计。
- 设置中可接入、停用并恢复原状态栏。独立辅助程序保留原命令输出，配置有备份并保护用户自行修改的内容。
- Claude Code 页面不显示重置卡、外部查看入口或每日 Token；Codex 原有重置卡与 Token 功能保持独立。

接入后，交互模式的 Claude CLI 会生成本机报告。QuotAI 在启动、接入或手动刷新时载入，不监听报告文件变化，也不主动查询服务器。刷新只重新读取本机记录。

官方状态栏不提供服务端采样时间。这里的百分比是会话最近报告，不是持续实时查询。

本机已验证 `claude -p` 模式不产生状态栏回调。这类自动化会话要展示额度，需要由启动 CLI 的宿主转发官方流式额度事件；本版尚未接入该转发通道。仅识别到会话不会生成额度数字。

已完成验收：

- 97 项测试通过，覆盖独立计时、重复报告、会话选择、缺失与过期数据、配置安装与恢复等边界。
- arm64 / x86_64 Universal 包构建通过，主程序与独立辅助程序的 ad-hoc 签名验证通过。
- 真实 Claude CLI 的官方状态栏报告已接入；安装版通过刷新载入，已核对 5h/7d 剩余额度、北京时间重置时间、逐窗口收到时间及来源提示。
- 安装版原生界面确认没有 Claude 重置卡、Token 区域或外部查看入口。
