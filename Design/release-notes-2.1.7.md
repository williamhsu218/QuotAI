# QuotAI 2.1.7

修复 Codex、Antigravity、Claude Code 切换时文字和选中背景可能跳出标签栏，以及切换反馈不自然的问题。

- 来源切换与 Antigravity 模型组采用 macOS 系统分段 Picker，由系统负责选择反馈、外观、键盘操作及辅助功能。
- 移除来源切换的自定义胶囊、几何匹配和字重动画，避免弹窗高度变化牵动标签文字。
- 设置标签的高亮限制在标签栏本地坐标，文字和图标保持固定。

提供 macOS 14+ 的 Apple Silicon / Intel Universal 安装包，采用 ad-hoc 签名，未进行 Developer ID 签名或公证。
