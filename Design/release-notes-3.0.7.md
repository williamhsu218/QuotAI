# QuotAI 3.0.7（70）

- 修复 Antigravity 2.34.0 更新后无法读取额度的问题。QuotAI 通过已登录的 Antigravity CLI 1.5.13 或更新版本读取 Gemini、Argon 和 Claude / GPT 的额度及重置时间。 [Antigravity CLI 安装说明](https://antigravity.google/docs/cli/tutorial)
- 面板底部标注 `CLI` 时，额度来自 CLI 当前登录的账号。要查看桌面端账号的额度，请在两端登录同一账号。CLI 路径省略套餐徽标。

已用 Antigravity 2.34.0 和 CLI 1.5.13 验证三组实际额度及 Token 活跃度。Universal 安装包支持 Apple Silicon 和 Intel，采用 Apple Development 团队签名，Developer ID 公证待完成。
