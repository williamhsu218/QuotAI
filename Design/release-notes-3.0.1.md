# QuotAI 3.0.1（54）

Widget 改为电池风格的同心额度环。每个供应商一组，7d 为外侧大环，5h 为内侧小环，中心显示对应供应商 logo。

- 中号显示最多三个来源，小号跟随菜单栏选中的来源。
- 各环独立表达剩余额度，0% 保持空环并明确标注；缺失或过期窗口显示虚线灰环和 `--`，历史结果灰显。
- 保留 Antigravity 当前模型组名称、最后更新时间和点击打开应用；不改变数据源、刷新策略、共享快照格式及通知设置。
- Codex/Claude 使用已有项目品牌素材，Antigravity 使用本机官方应用图标。Widget 与离线渲染共用布局及素材。
- 3.0.1（54）发布到 GitHub Releases 并标记为最新版；生产 appcast 指向已上传、下载校验通过的 Ed25519 签名包。
