# QuotAI 3.0.0 (52)

完成 2.3 工程整理并升级为可扩展的三来源架构；本次不新增来源。

- 统一 AppModel 与 Provider 注册表，集中保存来源可用性、刷新目标和通用额度投影；已有来源 ID、偏好键和缺数据不当成 0 的规则保持兼容。
- Services、Stores、Support 和可选功能数据层在 Core target 测试，CI 严格 swift-format；设置页异步验证 Codex 路径，不在视图渲染中扫描文件系统。
- 可选低额度及查询确认的重置通知：首次基线、跨阈值去重，历史/过期数据不触发。
- 可选本机额度趋势：24 小时/7 天/30 天、来源筛选、暂停与确认清空，私有原子 JSON，仅保留 30 天/12,000 条最小数据。
- WidgetKit 小/中组件通过同团队 App Group 共享最近查询，扩展不访问账户接口，过期隐藏、历史灰显。
- 可选 ⌃⌥Q 全局快捷键，使用系统注册热键，无需辅助功能权限；冲突时在设置提示。
- Claude 默认手动，允许用户开启 15/30/60 分钟低频查询，取消和超时规则保持不变。
- Sparkle 2.9.6 原生检查更新，自动检查/下载默认关闭，Ed25519 签名并在解压前验证；私钥保留本机钥匙串。
- 发布脚本默认只检查，显式发布要求干净且已提交的工作树；不再全量暂存用户变更。

## 验收状态

本机 159 项测试、严格格式检查、Debug 与 Universal Release 构建、全部隔离探针已通过。签名 QA 的 52→53 应用内更新、损坏签名拒绝及偏好保留已完成；中文浅色/英文深色设置、趋势空状态、快捷键和小组件共用视图已检查。

候选验证记录位于 `build/qa/upgrade-3.0.0/`。测试、Universal 构建、签名包、独立 QA 运行和真实安装状态分别记录在其中的 `verification.json`。

本次没有公开发行、替换 `/Applications/QuotAI.app` 或修改真实来源凭据。小组件需要团队签名，CI ad-hoc 包会提示共享不可用。本机只有 Apple Development 身份，Developer ID/公证、另一台 Mac 的首次运行、真实账户长时间查询及真实通知授权/桌面宿主验收不能由合成数据验证推断。
