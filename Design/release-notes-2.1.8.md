# QuotAI 2.1.8

来源切换与设置页采用同一种高亮滑块。

- Codex、Antigravity、Claude Code、模型组和设置标签复用同一个滑块组件，统一圆角、轨道、间距和过渡参数。
- 来源文字使用固定字重和固定位置，只有高亮背景横向滑动。移除跨窗口几何匹配，避免弹窗高度变化影响标签轨迹。
- 滑块由持久 Core Animation 图层驱动，快速反向点击从屏幕当前显示的位置继续，布局更新不会重启动画。
- 保留减少动态效果、选中状态辅助功能及设置的 Command-1…4 快捷键；数据内容及时切换，不跨来源插值。

提供 macOS 14+ 的 Apple Silicon / Intel Universal 包，采用 ad-hoc 签名，未进行 Developer ID 签名或公证。
