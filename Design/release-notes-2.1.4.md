# QuotAI 2.1.4

- OpenAI 套餐显示更新为 Pro 100 / Pro 200，兼容已有套餐标识与缓存。
- Claude Code 首次接入时读取并缓存套餐名称，启动和手动刷新时同步更新；无需先查询额度即可显示套餐。
- 套餐独立保存，不与 OpenAI 的 Pro 命名混用。退出登录、API 登录或未知套餐清除旧名称；读取暂时失败时保留缓存并注明来源。
- Claude Code 菜单栏改用 Anthropic 官方的经典 Claude Spark 图标，适配浅色与深色菜单栏。

套餐通过官方 `claude auth status --json` 读取，缓存仅包含格式版本与白名单套餐标识，使用 0600 权限和原子替换；不保存原始输出、邮箱或账号标识。清除查询缓存同时清除额度与套餐缓存。

Claude 额度仍使用原有官方 CLI 内置 `/usage`，只在手动刷新时查询，不持久化会话，禁用 hooks、MCP 和工具，只接受零轮次、零费用、空模型用量的结果。各窗口独立处理，不推算缺失额度、不显示账户每日 Token 或重置卡数量。

本版采用个人本机使用的 ad-hoc 签名，支持 macOS 14 及更新版本。

验证：112 项核心测试、隔离子进程与状态管理回归、Universal Release 构建与严格签名检查通过。本机 2.1.4（41）已运行，启动读取 Claude Pro 并生成最小套餐缓存；偏好设置、Claude 配置与原有 Claude 额度缓存保留。安装包与本机 App 的 9 个文件逐字节一致，安装版资源的经典图标在明暗外观下渲染通过。

界面已通过中英文渲染和原生隔离预览检查。实际安装版菜单栏弹窗的 CUA 读取持续超时，未取得该弹窗的截图与交互验收；此项与安装进程及资源验证分开记录。
