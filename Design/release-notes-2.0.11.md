# QuotAI 2.0.11

## 更新内容

- 菜单栏采用紧凑双行额度，缺少一个额度窗口时自动单行显示；供应商图标与 Stay Awake 咖啡杯顺序统一。
- 设置实时预览与实际菜单栏共用渲染组件，统一字号、间距、图标和状态说明。
- 修复额度分组失效后图标与数字可能不一致的问题；未知分组使用中性图标。
- 无额度数据时统一显示 `--`，不再使用固定示例百分比。
- “全部可用额度”选项更准确表达缺失窗口的处理；缩短分组名称并补齐选择器可访问标签。
- 修复独立交互预览与图片渲染入口的编译，增加分组回退、空数据和单窗口等回归测试。

## 安装与验证

- 版本：2.0.11，构建号 28。
- macOS 14+；Universal ZIP 同时包含 Apple Silicon 与 Intel 架构。
- 随附 SHA256SUMS-2.0.11.txt，可用于校验安装包。
- 68 项 Core 测试通过；独立原生设置预览完成来源、分组和单双行切换检查。
- 保留既有设置；Token M/B 单位、缓存统计与轻量读取策略不变，没有新增后台轮询。
- 沿用 ad-hoc 自签名，未使用 Apple Developer ID，也未进行 Apple 公证。

下载 ZIP 后解压，将 QuotAI.app 放入“应用程序”并替换旧版本。
旧版本发布与安装包保持不变。
