# QuotAI 2.1.6

- 来源、设置和 Antigravity 模型组切换器采用平滑胶囊过渡，遵循“减少动态效果”；数据内容即时切换，避免跨来源数字插值。
- 额度条统一圆角裁切并弱化阈值刻度，低额度保持真实填充比例；18 周 Token 活跃度网格与卡片内容对齐，新增月份坐标，复用日期和数字格式器。
- Antigravity 二级切换器与主面板统一，移除卡片边缘装饰条；Claude 采样口径移入可点击的信息说明，保留查询时间、历史结果和失败提示。
- 刷新中显示进度反馈；保持唤醒关闭时紧凑显示状态，保留模式与时长菜单；菜单栏数字按字体度量居中。
- Antigravity 使用原生临时 URLSession 和内存端点缓存，减少重复进程探测与 curl 启动。仅请求本机回环地址，拒绝重定向，限制响应大小；端点失败或进程退出后重新探测。
- Codex 与 Claude 阻塞进程 I/O 移到专用后台队列；Codex 重置卡确认采用异步等待；Claude 取消立即发送终止信号，由后台回收子进程，避免主线程等待。
- 自动刷新间隔修改后立即重新计时，弹窗关闭时暂停内部时间线，菜单栏时效更新继续运行。

基于外部评审逐项核对实现：采纳可验证的排版、交互、进程与调度优化；不采用会夸大低额度的最小填充宽度，不隐藏历史/失败提示，不变更已约定的北京时间口径，也不承诺未经测量的“10ms”性能数字。权限、额度耗尽、读取失败和各数据来源仍保持独立。

支持 macOS 14 及更新版本，提供 Apple Silicon / Intel 通用安装包。采用个人本机用途的 ad-hoc 签名，未采用 Developer ID 签名或公证。

验证：122 项核心测试、Codex 5 项协议/启动回归、Claude 查询生命周期探针、Antigravity 8 项状态回归及原生传输/缓存回归通过；Universal Release 和严格签名检查通过。原生界面检查覆盖英文浅色、中文深色、模型组切换、低额度、来源信息和关闭唤醒布局；本机正式版已读回 2.1.6（43），弹窗、手动刷新和设置入口通过检查。
Codex 与 Antigravity 真实账号只读刷新通过；正式版 Antigravity 模型分组及连续刷新已检查。
正式安装版与安装包全部 9 个文件一致；安装前后完整偏好一致，Claude 配置和套餐缓存保持不变；Claude 额度缓存升级时保留，随后随验收中的全来源手动刷新正常更新。保留 2.1.5（42）回滚包。
