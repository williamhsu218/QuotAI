修正 Claude Code 已登录但额度查询失败时的提示。

- Claude `/usage` 未返回订阅额度时，提示检查 CLI 网络连接并重试，避免笼统要求重新检查登录与套餐。

- 修复刷新完成后底部状态可能短暂误报“重置时间已过”的显示时序问题。

提供 macOS 14+ 的 Apple Silicon / Intel Universal 包，采用 ad-hoc 签名，未进行 Developer ID 签名或公证。
