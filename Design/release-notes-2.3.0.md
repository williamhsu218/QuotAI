# QuotAI 2.3.0

完成架构整理与工程化，保留现有来源、数据口径和设置值。

- 数据服务、Store 和日期格式化移入可测试的 Core target，测试覆盖缓存、取消、迟到结果与安装变化。
- DefaultsKey 集中定义偏好设置键；菜单栏、面板和设置共用来源可用性与回退规则。
- AppKit 菜单栏通过 Observation 跟随状态变化，保留时间驱动的失效更新。
- 统一 swift-format，CI 严格检查格式，并运行测试、Debug 构建、预览渲染、隔离探针和 Universal 打包。
- 设置页异步验证 Codex 路径并缓存显示结果，输入变化与应用重新激活时更新，不在 body 中扫描文件系统。
- 移除最低系统版本已覆盖的 macOS 13 判断。

这是 3.0 开发前的 2.3 候选检查点；尚未公开发布或替换正式安装。验证记录保存在 build/qa/upgrade-2.3.0/。
